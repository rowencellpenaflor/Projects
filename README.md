# Projects

⭕ **Data Science Projects**

The data science project folder contains 3 subfolders. These subfolders contain the activities on data science specialization such as summative and formative assessments.

➡️ In *Data Science 1*, the focus of the course is on Natural Language Processing, and Machine Learning techniques used for object classification, image segmentation and classifying emotions based on facial recognition and audio analysis. 

➡️ In *Data Science 2*, the focus of the course is on Data warehousing and utilizing data applications/tools/streaming such as Apache Kafka, Apache Spark, Apache Cassandra, Apache Hadoop and Apache Hive. This course also explored platforms such as Talend, SAS and PowerBI for managing, analyzing and visualizing data. 

➡️ In *Data Science 3*, this course emphasized Computer Vision and Image processing algorithms. The activity in this folder applies SVM, Naive Bayes, and YOLO algorithm as well Contrast Limited Adaptive Histogram Equalization and ZeroDCN as image enhancement techniques. It also dives contains an activity focusing on Time Series Forecasting techniques.

⭕ **Paw It Forward**

This folder contains the code of the **Paw It Forward** project. The goal of this project is to provide an interactive webpage with an integrated a database to a Facebook group, Paw-It Forward, to collect donations for stray animals. This project uses HTML, PHP, CSS and JavaScript in building the webpage and a MySQL for its database.
